# Фоны готического зала

Архив предыдущего оформления. После перехода на React новая публичная страница не использует эти фоны;
они сохранены вместе с историей генерации. Текущий дизайн описан в `docs/terminal-design.md`.

Созданы встроенным инструментом `imagegen` для публичной страницы Colday. В коде нет имён персонажей, логотипов или изображений из референса. Первые два фона экспортированы в WebP с качеством 93, версия `castle-hall-detail.webp` — без потерь. Размеры исходников не увеличивались.

| Файл | Фактический размер | Назначение |
| --- | --- | --- |
| `static/images/castle-hall.webp` | 1672 × 941 | Предыдущий широкий фон, сохранён для сравнения |
| `static/images/castle-hall-detail.webp` | 1672 × 941 | Текущий широкий фон с восстановленной фактурой, lossless WebP |
| `static/images/castle-hall-portrait.webp` | 941 × 1672 | Вертикальные экраны |

Страница выбирает изображение через `<picture>`. Поверх неподвижной архитектуры движутся световые волны, ограниченные маской окон, и четыре объёмных луча с независимыми циклами. Дополнительный слой того же изображения меняет яркость стекла. Пользователь может приостановить все эффекты, а `prefers-reduced-motion` отключает анимацию.

Для крупных мониторов ослаблены общая световая пелена, засветка и зерно поверх страницы. Редакция исходника улучшила читаемость фактуры, но генератор вернул 1672 × 941 вопреки запросу 3840 × 2160. Это не 4K: на QHD/4K фон всё ещё масштабируется браузером. Полное устранение недостатка разрешения требует исходника соответствующего размера.
